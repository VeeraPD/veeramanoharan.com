# Ensemble: PM portfolio writing kit

Prepared 23 October 2026. A curated editorial kit for explaining Ensemble as a **solo product builder**, without source code or execution logs.

## Read in this order

1. `01-pm-story/portfolio-brief.md`: the central narrative, audience, value proposition and your role.
2. `01-pm-story/product-decisions.md`: product choices, alternatives and tradeoffs.
3. `01-pm-story/claims-and-caveats.md`: which claims are anecdotal, measured or hypothetical.
4. `01-pm-story/blog-outline.md`: a suggested portfolio article structure and figure plan.
5. `02-evidence/`: the three study/audit reports, combined report and a simple eight-run CSV.
6. `03-publishing/`: latest first-person LinkedIn post, four-page carousel PDF, four PNG pages and an HTML viewer.

The story leads with my anecdotal iOS experience, explains the conditional opportunity on larger well-divided projects, shows how Ensemble works, and uses small-scale results as support. References to a team mean AI workers, not a human team.

No complete app source, generated implementations, harnesses, raw API logs, credentials, older drafts or visual backups are included. No additional paid model calls were made to create the kit. Personal paths in text have been replaced with placeholders. The PDF and PNG assets are unchanged copies of the latest versions.

MANIFEST.json identifies source documents. SHA256SUMS.txt verifies packaged file integrity. The underlying source material remains on the original project folders if deeper verification is later needed.
